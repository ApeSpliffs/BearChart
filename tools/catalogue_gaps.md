# Catalogue gaps

A backlog of what the catalogue is known to be missing, and what each entry
needs before it can be added. It is not data: `tools/build_data.py` never reads
it.

**Rule:** an entry is added to the catalogue only from a citable source (The
Build-A-Bear Wiki, an official Build-A-Bear page or press release). Nothing is
invented to fill a gap, and a sold listing title alone is not a source for a
new catalogue entry.
